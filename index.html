01
Syntax check

A bracket out of place?

ctn runs Python's AST plus a polyglot lexer to flag every unclosed bracket, dangling string, and style drift — in any of thirteen languages.

  • localRuns offline. No network. No account.
  • cloudOptional cloud re-check via any OpenAI-compatible endpoint.
  • coveragePython, JS, TS, Java, C, C++, Go, Rust, SQL, shell, PHP, Lua, plus a generic engine.
02
Security scan

Keys shouldn't live in your code.

Forty-plus rules cover hard-coded secrets, SQL concatenation, dangerous execution, weak crypto, sketchy paths — plus Shannon-entropy heuristics for keys hiding in what you thought were comments.

  • severityFour severities. critical, high, medium, low.
  • maskHits are auto-masked (e.g. sk-p********DfGh).
  • exportReports export to JSON or Markdown.
03
Diff

Two files. Your eyes lose to algorithms.

Each side accepts a local file or a cloud URL. ctn shows row-level and word-level deltas, then exports HTML, Markdown, or a unified patch.

  • modeLocal file, cloud fetch, or just paste.
  • highlightRow-level and word-level highlight.
  • ignoreToggle ignore-whitespace and ignore-case.
04
Prompt surgery

Turn fuzzy prompts into executable ones.

Paste the prompt you wrote for an LLM, pick goals (structured rewrite, role, ambiguity, token budget, few-shot), and let ctn re-write it through whatever API you wired up in Settings.

  • endpointsFully customisable URL, method, headers, body template.
  • responseJSONPath-style placeholder to extract the answer.
  • vaultAPI key encrypted on disk. Never written in plaintext.
Architecture

One file. Four engines.

All logic lives in ctn.py: one section per engine, the GUI is a thin Tkinter shell, async runners ferry work between them.

Local-first means your code never leaves the window.

Get going

Three lines. Download to running.

Any machine with Python 3.8+ — clone it, run it, ship it as an exe.

# clone + run
git clone https://example.com/ctn.git && cd ctn
python ctn.py

# self-check (English CLI)
python ctn.py --selftest

# compile a native one-file binary (Nuitka)
build.bat            // Windows
./build.sh           // macOS · Linux
→ dist\ctn.exe
